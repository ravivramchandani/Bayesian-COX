## Put the finished source on Overleaf

1. Download and extract the source ZIP.
2. Open the shared Overleaf project with an account that can edit it.
3. Use Upload above the file list to upload the extracted source files and folders. Preserve the folder structure and replace matching files. Keep `Main.tex` at the project root.
4. Select `Main.tex` as the main document and pdfLaTeX as the compiler, then Recompile.
5. Check that the title is Explainable Bayesian Survival Models and the output has 92 pages.

Alternatively, from the Overleaf dashboard choose New Project, then Upload Project, and select the ZIP. [Overleaf's upload instructions](https://docs.overleaf.com/managing-projects-and-files/adding-files-to-a-project/uploading-files-to-a-project) describe both file and folder uploads. The ZIP excludes the precompiled Main.pdf; the PDF is downloaded separately above.

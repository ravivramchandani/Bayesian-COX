## Open and edit the report

1. Open the shared Overleaf project.
2. Select `Main.tex` as the main document and pdfLaTeX as the compiler.
3. Click Recompile to view the report.
4. Edit the text in this same project, then recompile before downloading the PDF.

The report is titled **Explainable Bayesian Survival Models**. No manual source upload is needed. Reading and editing require only a browser on any operating system; no experiment run, SSD or model-software installation is needed.

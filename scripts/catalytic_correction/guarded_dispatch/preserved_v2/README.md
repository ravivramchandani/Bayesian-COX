# Prospective guarded dispatch: corrected preparation v2

V1 is preserved byte-for-byte under `preserved_v1/` and is not adopted. Its sealed
independent review, genuine fictional counterexample capture and failed test
evidence are under `preserved_v1_review/`. V2 addresses GD-R1/R2/R3; independent
review of these exact finished v2 bytes remains required before actual use.

This external preparation implements the accepted engineering design. It has not
dispatched a real controller, created any actual review, selection or freeze, or
certified numerical, scientific or release completion. Root must review these
exact sealed bytes before integrating or using them. The tests use invented
two-cell metadata and injected subprocesses; they also use the unchanged original

selection bootstrap. No scientific backend, checker, array or target result was
loaded. These fixtures do not prove a real 1,625-cell execution.

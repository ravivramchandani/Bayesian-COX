\chapter{Calibration Across Evaluation Horizons}
\label{app:predictive}\label{app:prediction}

The main results present calibration at the median training-event horizon. The following tables report all three evaluation horizons: the 25th, 50th and 75th percentiles of event times in each outer-training partition. These percentiles define fold-specific times within each cohort's endpoint and unit.

Calibration-in-the-large is the IPCW complementary-log-log calibration intercept estimated with slope fixed at one. Calibration intercept and slope come from the weighted horizon-specific model described in Chapter~\ref{chap:methods}. Reference values are zero for calibration-in-the-large and intercept, and one for slope. Entries are means and sample standard deviations across accepted outer folds.
